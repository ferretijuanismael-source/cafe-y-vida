# Café y Vida — página tipo Linktree

Incluye página pública, botón Presentación con PDF reemplazable y panel `/admin`.

## Prueba local
`npm install` y luego `npm start`.

Público: `http://localhost:3000`
Admin: `http://localhost:3000/admin`
Contraseña de prueba: `cafevida2026`

Para Internet necesitás un hosting Node.js con almacenamiento persistente. Luego se puede mejorar el panel para cambiar fondo, logo y enlaces desde la propia web.
